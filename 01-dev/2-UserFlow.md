# NearSafe User Flow

## 0. 核心設計原則
- **推播是主角**：80% 的使用者價值發生在「App 關閉」時
- **進 App 次數越少越好**：理想情況下，使用者一週只開 1-2 次
- **冷啟動 3 分鐘內完成**：從下載到收到第一則測試通知

---

## 1. 首次使用流程（Onboarding）

```
下載 App
  ↓
歡迎頁（一句話說明價值）
  ↓
權限請求（分兩步，降低拒絕率）
  ├─ Step 1: 定位權限（必須）
  │    └─ 說明：「用來計算事件離你多遠，不會上傳你的即時位置」
  └─ Step 2: 推播權限（必須）
       └─ 說明：「不開推播 App 就沒意義了」
  ↓
新增第一個關注地點
  ├─ 預設引導：「先加『家』試試看」
  ├─ 搜尋地址 or 拖曳地圖 or 使用目前位置
  └─ 設定半徑（預設 3 km）
  ↓
選擇事件類型（預設全開，可取消）
  ↓
選擇通知頻率（預設「一般模式」）
  ↓
發送一則測試推播（關鍵！證明系統有在運作）
  ↓
完成 → 進入首頁
```

**設計重點**
- 不要求註冊帳號（V1 完全本地化，用 device ID）
- 測試推播是信任建立的關鍵步驟

## 2. 核心循環：收到事件推播

### 2a. 使用者在 App 外（主要情境，90%）

```
事件發生
  ↓
後端 AI pipeline 判定命中某使用者的關注半徑
  ↓
推播送達裝置（鎖屏 / 通知中心）
  ↓
使用者看到標題 + 短句
  ↓
三種反應：
  ├─ A. 已足夠資訊 → 直接滑掉（最常見）
  ├─ B. 想看地圖 → 點通知 → 跳到地圖頁並聚焦該事件
  └─ C. 回饋訊號 → 長按通知 →「有幫助」/「太吵了」
```

### 2b. 通知欄快捷動作
- **有幫助** → 提高此類事件在此地點的敏感度
- **太吵了** → 降低敏感度，60 分鐘內同類事件靜音
- **查看地圖** → 深層連結進 App

### 2c. 使用者在 App 內（次要情境）
- 地圖直接跳出事件 pin 閃爍 + 底部 toast
- 不發推播（避免重複打擾）

## 3. 主要頁面與動線

### 頁面 A：首頁（地圖）
```
[地圖佔 80% 畫面]
  - 自己位置（藍點）
  - 關注地點（深色 pin + 半徑圈）
  - 事件（紅色 pin，有動畫）
[底部 Sheet，可上拉]
  - 最近 3 則事件卡片
  - 每張卡：事件類型 icon + 距離 + 時間 + 一行摘要
  - 點卡 → 地圖聚焦 + 展開詳情
```

### 頁面 B：關注地點列表
```
[頂部 + 按鈕：新增地點]
[卡片列表]
  - 每張卡：
    - 地點名稱（家/公司/…）
    - 地址
    - 半徑（可直接調整）
    - 目前狀態（通知開/暫停）
    - 最近 7 天事件數
  - 長按卡片：編輯 / 刪除 / 暫停
```

### 頁面 C：設定
```
- 事件類型開關（6 類，checkbox）
- 通知頻率（3 選 1 radio）
- 勿擾時段（例：23:00-07:00 不推非緊急）
- 資料來源（V2 才開放選擇）
- 關於 / 回報問題
```

## 4. 關鍵邊界情境

| 情境 | 處理方式 |
|------|---------|
| 使用者出國 | 自動偵測時區變動 → 詢問是否暫停所有通知 |
| 同一事件多來源 | 後端去重後只推一次；若嚴重度升級才補推 |
| 網路斷線 | 推播走 FCM/APNs，不依賴 App 存活；App 開啟時同步最近 24h 事件 |
| 使用者一直標「太吵」 | 連續 5 次後跳彈窗建議切換到「超嚴選」 |
| 關注地點重疊 | 事件只匹配「最近」的那個地點，避免重複推播 |
| 半夜發生重大事件 | 嚴重等級 ≥ 高 時無視勿擾時段 |

## 5. 使用者旅程時間線（典型一週）

```
週一 20:00  新增「補習班」為關注地點
週二       無通知（正常）
週三 18:30  推播：補習班 800m 火警 → 改道
週四       無通知
週五 22:15  推播：住家 1.2km 持刀事件 → 關窗
週六 10:00  打開 App 看地圖，確認無事
週日       無通知
─────────
本週主動開 App：1 次
本週收到通知：2 次（皆有幫助）
```

→ 這個節奏就是「成功」的定義。每週推播 > 10 次 = 過度敏感，< 1 次 = 使用者會忘記裝過。

---

## 6. V1 不做的事（避免 scope creep）
- ❌ 帳號系統 / 跨裝置同步
- ❌ 社群功能 / 使用者爆料
- ❌ 聊天機器人 / AI 對話
- ❌ 付費訂閱
- ❌ 歷史事件統計圖表
- ❌ Widget / Apple Watch
- ❌ 國際化（V1 只做繁體中文 + 台灣）
