---

## 1. 定位與一句話說明

**名稱**: NearSafe · 家人守護

**一句話**: 「當你關心的人家附近發生重大危險時, 第一時間通知你, 並提供一鍵關心的行動。」

**類別**: 生活工具 / 家庭連結

---

## 2. 核心理念

| 關鍵字 | 內涵 |
|--------|------|
| **關心, 不是監控** | 不追家人的實時定位。只追「事件」。與 Life360 的根本區隔。 |
| **推播 + 行動, 不是訊息流** | 推播必含 1-tap 行動 (致電/Line/安全詢問), 不做新聞 feed。 |
| **雙向同意** | 被關注者要同意、可隨時拒絕、看得到「誰在關心我」。紅線。 |
| **AI 在背景過濾** | 使用者沒有對話框。AI 只做事件分類、去重、摘要短句。 |

---

## 3. 核心情境 (取代原案)

### 情境 1: 北漂子女 → 家鄉父母 (主情境)
```
週三 15:47
你在台北上班寫 email
手機震一下 → 通知:
┌──────────────────────────────────────────┐
│ 🔥 台中爸爸家 1.2km 大樓火警              │
│ 西屯區 XX 路, 已封路                       │
│ 爸 10 分鐘前有傳早安 Line                  │
│ [致電爸爸] [傳 Line 關心]                 │
└──────────────────────────────────────────┘
```
按「致電爸爸」→ 撥號 + 自動把事件摘要同步到家族 care feed。

### 情境 2: 父母 → 補習中的小孩
```
週四 20:15 媽媽煮飯中
┌──────────────────────────────────────────┐
│ ⚠️ 小明補習班 600m 疑似群體衝突            │
│ 建議先打電話確認                           │
│ [致電小明] [安全詢問 Line]               │
└──────────────────────────────────────────┘
```
按「安全詢問」→ 系統自動傳 Line: 「媽媽想確認你安全, 回『安全』即可。」

### 情境 3: 被關注者端的情感
```
爸爸打開 app:
┌──────────────────────────────────────────┐
│ 關心你的人                                 │
│ · 小華 (女兒) · 台北 · 已連線 3 週          │
│ · 小明 (兒子) · 台北 · 已連線 1 週          │
│ 過去 7 天無事件                            │
└──────────────────────────────────────────┘
```
這份「清單本身」就是情感價值。Life360 做不到, 因為那是監控。

## 4. 問題與解決方案

### 現在的問題
- 台灣已有 PWS 國家級警報、氣象署 E、KNY 速報, 但都只處理「大型自然災害 + 官方廣播」
- 日常局部事件 (火災/交通/暴力) 在官方 app 外無個人化半徑通報
- 新聞 app 太吵、Threads 真假難辨、家族群組也無系統
- 真正的痛點: **北漂族無法主動得知「家人附近」的事件**, 只能被動等新聞或等家人打來

### NearSafe 的解
- 以「我關心的人」為中心 (非「我」)
- 地點半徑 + 事件類型 + AI 過濾 → 低頻、高精確的推播
- 推播內建行動按鈕, 把「得知 → 關心」壓縮到 1-tap
- 雙向同意機制保護被關注者

## 5. V1 核心功能

### 5.1 關注對象 (家人邀請制)

- 使用者可邀請 1-5 位家人
- 流程:
  1. 設定者端: 點「邀請家人」→ 產生 8 字元短碼 + QR Code + deep link (`nearsafe://invite/XXXXXXXX`)
  2. 透過 Line 把 QR/link 傳給家人
  3. 家人端: 打開 app 掃碼 / 貼碼 → 看到「小華想關心你, 接受?」→ 同意/拒絕
  4. 同意後建立 `relationship`, 設定者可新增該家人的關注地點

- 每位家人可設 1 個關注地點 + 半徑 (1/3/5 km)
- 被關注者隨時可從自己 app 內「關心你的人」清單移除任何設定者 (單向決定)

### 5.2 事件類型 (V1 鎖 3 類)

為了執行聚焦 + 情感門檻高, V1 **只** 處理:
- 大型火災 / 爆炸
- 疑似暴力事件 (持刀、群毆、槍)
- 大型交通事故 (多車、長時間封路、人員傷亡)

**砍掉不做**: 自然災害局部災情 (PWS 已覆蓋)、公共秩序混亂 (模糊且主觀)、危險物外洩 (頻率太低)

### 5.3 通知設計

**標題**: `[事件類型 emoji] [被關注者名稱]家 [距離]` 例: `🔥 爸爸家 1.2km`

**內容 (AI 生成, ≤40 字)**:
- 地點: XX 區 XX 路
- 狀態: 封路 / 濃煙 / 警方封鎖等
- 建議行動: 一句話

**行動按鈕 (V1 必包)**:
- 致電 [名字]
- 傳 Line 關心
- 安全詢問 (Line 自動傳「請回『安全』確認」)
- 查看地圖

**回饋按鈕** (長按通知):
- 有幫助 → 下次此類事件敏感度 +
- 太吵了 → 60 分鐘內同類靜音 + 下次敏感度 -

### 5.4 頁面 (V1 只 3 頁)

1. **首頁** = 地圖 + 家庭 care feed
   - 地圖: 自己 + 所有被關注家人位置 (只是他們的「家」, 不是實時定位) + 半徑圈
   - 底部 sheet: 家庭共享 timeline (事件、打電話紀錄、安全回報)
   - 空狀態: 「過去 7 天一切平安」

2. **關心的人** = 被關注者清單
   - 每張卡: 名字、關係、地址、半徑、連線狀態
   - 長按: 修改 / 暫停 / 移除
   - 頂部 + 按鈕: 「邀請家人」

3. **設定**
   - 事件類型開關 (3 類)
   - 通知頻率 (嚴格 / 一般 / 超嚴選)
   - 勿擾時段 (嚴重度 4+ 仍會推)
   - 關於 / 回報

## 6. AI 在這個 app 裡做的事

使用者看不見 AI, 它在背景:

1. **事件分類**: 新聞 / 官方通報 → 是否安全事件 → 哪類 → 嚴重度 1-5
2. **地點解析**: 「XX 商圈附近」→ 經緯度 (正規化 + Google Geocoding fallback)
3. **去重**: 同事件多來源 → 時間 + 位置 + 文字相似度判定 → 只推一次
4. **生成推播短句**: 冗長通報 → ≤40 字

**模型**: Claude Haiku 4.5 (主力), Sonnet 4.6 (嚴重度爭議時 escalate, <5% 流量)

---

## 7. 紅線 (絕不破)

- ❌ 不追實時定位 (只存關注地點, 不追人)
- ❌ 不洩漏「誰關注你」給第三方或 watcher 間互看
- ❌ 不接廣告 SDK / tracker
- ❌ 不做焦慮放大設計 (例: 「家人今天沒回你」)
- ❌ 推播文案絕不含具體門牌, 僅路口/區段

---

## 8. 關鍵 KPI 與 Kill-switch

**內測期 (M5) 就要看**:
- D7 retention ≥ 40%
- 每週有效推播 / 用戶 = 1-3 則
- 推播 → 行動率 ≥ 30%

**Kill-switch (內測 7 天)**:
- D1 retention <60% → scope 錯, 回頭改
- 誤報率 >20% → pipeline 不能用

**上線後**:
- 30 天未達 500 用戶 → persona 錯, 換 GTM

## 9. 冷啟動 Persona

**主要 persona**: 北漂子女
- 20-35 歲
- 在台北/桃園/新竹上班或讀書
- 父母在中南部 (台中/嘉義/台南/高雄)
- 有 Line, 每週跟父母通話 1-3 次

**行銷渠道**: Threads / Dcard 北漂主題社群 + 北漂族 Facebook 群組

**次要 persona (V2 再打)**: 家長監護小孩 (補習班路線)、情侶互相守望

---

## 10. 不做的事 (V1 NOT in scope)

| 項目 | 原因 |
|------|------|
| 實時家人定位 | 違背「非監控」哲學 |
| 群眾回報 / 爆料 | 假訊息風險 + AI 過濾成本未驗證 |
| 付費訂閱 | 未驗證 retention 前不談 |
| 廣告 SDK | 永不 |
| Widget / Apple Watch | V2+ |
| 國際化 | V1 只台灣 |
| 自然災害 / 公共秩序 / 化學外洩 | V1 3 類已夠, PWS 已覆蓋自然災害 |
| 帳號系統 | V1 用 device_id, V2 再做 |

---

## 11. 尚未驗證的前置 (使用者承擔風險)

- T1: 7 天資料源頻率驗證 (一週真事件 ≥10 則?)
- T2: 5 場北漂子女訪談 (情感強度 + 付費意願 ≥$30/月?)

兩者跳過。若 M5 內測指標不達標, 依 Kill-switch 退場。
