# 真機回歸檢查表（裝 TF build `07240928`）

> 回報方式：哪一條卡了就截圖丟給我，標一下條號。⭐＝只有真機能驗的重點。

## A. 單機流程（一台手機就能測）
1. **全新體驗**：刪 App 重裝 → 「點一下地圖找到你家」→ 點地圖 → 定位授權 → 進主畫面（全程應 ≤3 個決定）
2. 安心頁：單人狀態顯示「守護中：你」＋事件串（附近 10 公里內）
3. 地圖：調整警戒圈（點圈 → 滑桿 → 完成），半徑改了地圖圈跟著變
4. 「警報跟著我」開關：關→圈變固定；開→圈跟人
5. 新增重要地點（住家/公司點選）→ 地圖出現第二個圈
6. **通知**：設定 → 提醒設定 → 勿擾與吵醒各檔位切換不閃退
7. **深色模式**整體掃一遍——特別是選身分頁（上次的鬼畫面就在這）
8. iPad 直向＋橫向各掃一遍主要頁面

## B. 家庭閉環（要兩台裝置、兩個 Apple 帳號）
9. A 機：家人頁 → 邀請家人 → 登入預告卡 → Apple 登入成功
10. A 機：邀請卡顯示 QR＋邀請碼＋**效期日期**；按「重新產生」碼有換
11. **B 機用相機掃 A 的 QR** → 「要在 HavenCircle 中打開嗎？」→ 打開 → 登入 → 確認頁顯示「你即將加入 ○○ 的家庭圈」→ 加入
12. B 機：🎉「已加入「○○」！」→ 選身分 → **兩題激活**（位置分享、通知）——試一次「先不用」、試一次都開
13. 兩機家人頁：互相看得到對方的成員卡＋「我的帳號」卡在最頂
14. A 機（App 開著或重開）：有沒有「○○ 已加入你的家庭圈 🎉」通知
15. B 機開位置分享 → A 機地圖看得到 B 的即時圈
16. 互發「回報平安」→ 對方收到通知＋已讀回條
17. **退出家庭圈**（B 機）：確認文案 → 退出 → B 回到空狀態、A 那邊 B 消失
18. **刪除帳號**（可用測試帳號）：兩層確認 → Apple 再驗證 → 刪完回到全新著陸頁

## C. 關鍵基建
19. ⭐ **Production 推播**（最重要的一項）：TF 版通知開著，等一則真實 CWA 警報（台灣小震很常見，一兩天內通常會有）；若兩天沒等到跟我說，我從 Oracle 中繼站對 production 權杖發一則測試廣播
20. 輸錯邀請碼／過期碼：錯誤訊息是人話不是代碼
21. 單人在事件詳情按「我平安」→ 情境邀請卡出現
