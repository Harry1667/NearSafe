## 模塊 A — 帳號 / 登入（#1 #2 #11 #13 #14）

- [ ] **A1（#2 登入即時刷新）** 家人頁未登入 → 點「登入」→ 完成 Apple 驗證。
  - 預期：**不需下滑刷新**，家人頁「我的帳號」立刻變成已登入態、顯示你的名字。

- [ ] **A2（#13 帳號狀態自動）** 登入後直接切到別的分頁再切回家人頁；或把 App 切到背景再回前景。
  - 預期：帳號/家庭狀態自動反映，不需手動點「重新檢查帳號狀態」。（該按鈕現在只是備援。）

- [ ] **A3（#1 刪帳號不卡死）** 設定 → 刪除帳號與所有資料 → 二次確認 → Apple 驗證。
  - 預期：確認步驟仍在（保命，不可逆動作要確認）；但驗證後不會無限轉圈——最多約 30 秒內一定有結果，網路不穩會顯示「網路逾時，請重試」而不是卡死。

- [ ] **A4（#11 登出退家庭）** 到 iOS「設定 → Apple 帳號 → 密碼與安全性 → 使用 Apple ID 的 App」把安心圈的授權移除（或登出 Apple 帳號），回到 App。
  - 預期：App 偵測到憑證撤銷，自動退出登入與本機家庭圈顯示。**雲端家庭成員資料不會被刪**。

- [ ] **A5（#11 回來加回原家庭）** 用**同一個 Apple 帳號**重新登入。
  - 預期：自動加回原本的家庭圈（靠 uid 反查），不用重新邀請。

- [ ] **A6 ⚠️（#14 掃 QR 加入）** 家人 A 產生邀請 QR，家人 B 用相機掃。
  - 預期：B 的 App 開啟後**自動跳出**「你即將加入 ○○ 的家庭圈」確認卡，可直接加入。
  - 註：這條程式碼鏈路已完整，你之前看到「只開 App 沒反應」很可能是舊 build，請務必用新 build 測。
  - 已知限制：A（圈主）要看到「某人加入了你的家庭」目前是**本機刷新時**才比對出來（開 App／回前景／下拉），不是伺服器即時推播——這是列入之後 Blaze 方案的 P1，這次不含。

## 模塊 B — 家人頁面（#4 #9 #12 #15 #16 #17）

- [ ] **B1（#16 邀請置頂）** 未加入家庭時看家人頁。
  - 預期：「邀請家人」大按鈕在**最上方**（未登入時顯示「登入並邀請家人」）。

- [ ] **B2（#16 輸入邀請碼入口永遠在）** 分別在「未入圈 / 已入圈單人等待 / 已入圈多人」三種狀態看家人頁。
  - 預期：**三種狀態都有**「輸入邀請碼加入」入口，點了能開輸入碼畫面。

- [ ] **B3（#16 家庭卡可點入）** 已加入家庭時，看最上方「我的家庭・N 位成員」卡。
  - 預期：可點進去看成員清單/詳情。

- [ ] **B4（#9 icon 不消失）** 檢查「邀請家人」「輸入邀請碼加入」「再次分享」「新增守護地點」等按鈕。
  - 預期：每個按鈕**文字置中且前面的圖示都在**（先前 icon 被擠掉的問題已修）。順便看邀請碼頁的「重新產生邀請碼」「用訊息或 AirDrop 分享」也有 icon。

- [ ] **B5（#15 名字不被身分蓋掉）** 設定 →「你的名字與家庭身分」→ 填本名（例如「王大明」）。再回家人頁或安否流程選一次身分（例如「爸爸」）。回設定看本名。
  - 預期：本名**仍是「王大明」**，不會被「爸爸」蓋掉。家人清單你自己那列顯示本名為主、〔爸爸〕為輔。

- [ ] **B6（#4 守護地點加得進去）** 家人頁 →「新增守護地點」（或右上「+」）→ 選/命名地點 → 進到警戒圈設定。
  - 預期：sheet 正常彈出；若還沒確認位置，畫面**底部常駐一條提示**「請先確認地點位置：搜尋地址、點『用目前位置』、或在地圖點一下」，照著做任一項後「儲存」就能按。不再出現「怎麼按都加不進去、也不知道為什麼」。
  - （住家類新地點且已給定位權限時，會自動帶入目前位置當預設。）

- [ ] **B7（#17 沒有假家人入口）** 看右上角「+」。
  - 預期：只有「新增守護地點」，**沒有「新增家人」**（那個手動建假家人卡的入口已移除）。

- [ ] **B8（#12 整體流程）** 走一遍：未登入→登入→邀請/加入→看成員→新增守護地點。
  - 預期：整條順、不斷。有任何一步卡住或困惑記下來。

## 模塊 C — 設定 / 個人資訊 / 字體 / 深色（#5 #6 #7 #8）

- [ ] **C1（#7+8 名字設定不再是空殼）** 設定 →「你的名字與家庭身分」。
  - 預期：這頁能**真的設定**——本名輸入框、六格身分快選（爸爸/媽媽/兒子/女兒/阿公/阿嬤）＋自訂稱呼、緊急聯絡備註，都能填。不再是點進去什麼都不能做。

- [ ] **C2（#7+8 帳號卡不誤導）** 設定看最上面的帳號卡。
  - 預期：文案是「Apple 帳號」/「登入 Apple 帳號」，**不再寫「設定你的名稱」**（那頁只管登入/登出/刪號，改名請到 C1）。

- [ ] **C3 ⚠️（#5 字體大小有效）** 設定 → 字體大小 → 切到「特大」或「最大」。
  - 預期：主要畫面文字**明顯變大**（家人頁、設定頁、事件清單等語意字體都會縮放；地圖圈名/時間戳這次也改成可縮放）。
  - 註：接線經確認正確（切「大」＝系統 xLarge 級距）。若你之前覺得「完全沒變」，很可能是舊 build——請用新 build 複驗。地圖上的 icon 尺寸是刻意固定的，不會變。

- [ ] **C4 ⚠️（#6 深色模式）** 設定 → 外觀 → 分別切「淺色 / 深色 / 跟隨系統」；也試著在 iOS 控制中心切系統深色，看 App 有沒有跟上。
  - 預期：切換即時生效、不卡住、文字背景都正確變色。
  - 註：這次全庫顏色逐處核對，**沒找到**會導致深色失效的硬編碼色，系統深色實測正常。若你用「App 內外觀選擇器」切還會卡住，請記下**確切怎麼操作觸發的**（例如「設深色後進哪一頁才卡」）回報我，我針對那條路徑深挖。

## 核心保命流程回歸（每次改版都要測）

- [ ] **R1 我平安按鈕** 首頁/家人頁/通知動作三個入口各按一次「我平安」。
  - 預期：成功才顯示「已送出」；沒登入會引導登入而不是假成功；離線/慢網最多約 8 秒內給明確結果，不會黑洞卡住。

- [ ] **R2 通知演練** 家人頁/設定進「通知演練」→ 開始演練。
  - 預期：演練前檢查（通知權限、災害警報通知已啟用、未暫停、有警戒圈）狀態正確；開始後走完「判斷→推播→解除」，收得到演練通知。

- [ ] **R3 警報靜音兩軸** 設定的「提醒設定」看「僅重大/標準/靈敏」與「絕不吵醒」。
  - 預期：兩軸分工清楚（一個是收哪些等級、一個是要不要吵醒），文案不誤導。

- [ ] **R4 真機推播（最關鍵）** 用兩台真機（或一台真機＋後端）觸發一次真實警報。
  - 預期：鎖屏能收到推播。這條只能真機測，模擬器測不出來。
