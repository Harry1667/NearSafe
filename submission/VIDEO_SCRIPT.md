# 安心圈 HavenCircle — Demo 影片腳本（初賽提交）

> 總長：**110 秒**（目標區間 90–120 秒）
> 拍攝環境：實機 iPhone（通知、CloudKit 需實機）；家人回報一幕需第二台裝置或預錄畫面
> 原則：所有畫面都是 App 現有功能，示範資料一律帶【示範】／【歷史示範】字樣（誠實原則），旁白不宣稱未完成的功能

---

## 逐場腳本

### 場 1｜0–10 秒（10s）：開場鉤子——通知落在鎖定畫面

- **畫面**：黑底淡入 → iPhone 鎖定畫面特寫，跳出通知「【示範】地震速報：臺北市南港區——官方確認事件落在『住家』提醒範圍內」
- **旁白**：「爸媽住得遠。災害發生的當下，你想知道的其實不是他們人在哪裡——而是**他們住的地方**，有沒有事。」

### 場 2｜10–22 秒（12s）：定位宣言——零位置追蹤的生活圈

- **畫面**：新手教學歡迎頁（「所有生活圈與事件資料只儲存在這支手機；不會追蹤任何人的即時位置」）→ 切到生活圈設定：搜尋長輩家地址 → 地圖出現提醒半徑圈
- **旁白**：「安心圈不追蹤任何人的位置。你只要設定家人的生活圈——住家、長輩家——我們監看**官方災害示警**是否落在這些範圍附近。地址不上雲端，只存在這支手機。」

### 場 3｜22–42 秒（20s）：收到警報——分類清楚、理由透明

- **畫面**：點開場 1 的通知 → deep link 進「提醒中心」分頁 → 看到「需要注意」分類裡有官方確認事件（來源：內政部消防署）→ 點進事件詳情，鏡頭停在「為何收到」理由列（例：「事件位於長輩家的『住家』生活圈約 X 公尺內，官方已確認」）
- **旁白**：「警報來了，App 先講清楚三件事：這是**政府 NCDR 民生示警的真實資料**、它為什麼跟你有關、可信度是什麼。每一則通知都看得到『為何收到』；未經驗證的線索只在 App 內顯示，**絕不推播打擾你**。」

### 場 4｜42–62 秒（20s）：安全地圖——塗層、圖例、真實避難資源

- **畫面**：切到「安全地圖」分頁（預設分頁）→ 區域警報以**行政區塗層**呈現，角落展開圖例（嚴重度色階）→ 打開避難所／醫院圖層，點一個真實避難所 → 事件詳情的「導航」按鈕
- **旁白**：「地圖上，強風豪雨這種整區的警報用**行政區塗層**呈現，不用會誤導的大頭針。避難收容所、急救責任醫院是**政府開放資料，全國近六千筆**——導航按下去，是真的地點。」

### 場 5｜62–80 秒（18s）：安否回報——一鍵平安、已讀回條

- **畫面**：「家人」分頁 → 長輩手機按下「我平安」→ 切到子女手機：家人回報清單即時出現該筆回報，下方顯示「已讀：⋯」回條
- **旁白**：「事情發生後，最重要的一句話是『我平安』。長輩一鍵回報，全家透過 iCloud 家庭圈即時看到，還有已讀回條——你知道媽媽報了平安，媽媽也知道你看到了。」

### 場 6｜80–97 秒（17s）：真資料架構——不是假 Demo

- **畫面**：切到提交網頁的架構圖區塊（NCDR 43 類示警 → Mac Mini 爬蟲每 5 分鐘 → Oracle 中繼站 → App），可疊上終端機 log 或中繼站 JSON 回應的實拍畫面
- **旁白**：「這些全是真的：我們自建爬蟲**每五分鐘**抓取 NCDR 四十三類政府示警，經 Oracle 中繼站整理後供 App 即時拉取。APNs 推播的 App 端垂直切片已經就緒，後端發送服務建置中。」

### 場 7｜97–110 秒（13s）：收尾——一句差異化

- **畫面**：黑底白字打出「Life360 追蹤**人**。安心圈守護**範圍**。」→ App 圖示 + 「安心圈 HavenCircle」+ 官網 havencircle.looptw.com
- **旁白**：「Life360 追蹤人，我們守護範圍——不看家人在哪，只看家人身邊安不安全。安心圈，讓關心剛剛好。」

## 拍攝備忘（每場對應的 App 操作）

| 場 | 怎麼做出這個畫面 |
|---|---|
| 1 | 設定分頁 →「示範與開發」→ 按「模擬警報通知（示範用）」→ **5 秒內鎖定螢幕**，通知會落在鎖屏（標題自帶【示範】字樣，符合誠實原則）。錄屏前先把其他 App 通知關靜音。 |
| 2 | 用「刪除帳號與資料」或全新安裝重跑新手教學（共 6 步，登入步驟可跳過）。歡迎頁有「不追蹤任何人的即時位置」文案；生活圈步驟示範地址搜尋＋半徑圈。 |
| 3 | 點場 1 的通知會 deep link 到提醒中心（`havencircle://alerts`）。要讓「需要注意」分類有官方事件：先在「家人」頁把一個生活圈設在**彰化縣福興鄉**（長輩家），再按設定頁「載入歷史官方事件示範」——會載入 2 筆 NCDR 真實歷史示警（彰化工廠火災＋花蓮台9線封路，標題含【歷史示範】），火災事件就會命中該生活圈、進「需要注意」。點進詳情拍「為何收到」理由列。 |
| 4 | 安全地圖分頁。區域警報塗層吃即時 NCDR 資料（夏天多半有高溫／雷雨示警）；若當下全無警報，改以「載入歷史官方事件示範」的事件點＋圖例＋避難所圖層為主。圖層選單開「避難所／醫院」；治安、空品層可帶一秒但不必講解。拍前確認圖例面板有展開。 |
| 5 | 需兩台實機、兩個 iCloud 帳號，且 CKShare 邀請已完成（流程見 `CLOUDKIT_SETUP.md`）。拍攝順序：裝置 A（長輩）按「我平安」→ 裝置 B（子女）下拉刷新看到回報 → 停留在「已讀」回條出現。若跨帳號環境來不及備妥，此幕改用單機畫面：安否回報頁的回報清單＋已讀回條 UI，旁白不變（功能已實作，僅拍法不同）。 |
| 6 | 直接錄提交網頁 `website/pitch/index.html` 的架構圖區塊滾動畫面；加分做法：疊一段 `curl` 中繼站 API 回傳 JSON 的終端機實拍（證明 `source: official-api`）。 |
| 7 | 純字卡＋App 圖示，剪輯軟體內完成，不需 App 畫面。 |

**收尾檢查**：拍完後按設定頁「重設 Demo 資料」清掉所有【歷史示範】與演練事件，避免正式畫面混入示範資料。
