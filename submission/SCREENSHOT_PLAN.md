# 安心圈 HavenCircle — 6 張敘事截圖拍攝規格（初賽提交）

> 目的：讓評審在滑過網頁時，靠 6 張圖就讀懂完整故事線——
> **本人同意位置分享 → 即時圈／固定圈 → 收到警報 → 看懂地圖 → 理由透明 → 家人平安**。
> 圖檔落點：`website/pitch/img/`，檔名如下（網頁 `<img>` 已按此命名引用）。
> 建議規格：實機 iPhone 直式截圖（淺色模式優先，狀態列時間調整為 9:41 可加分），PNG 原尺寸。
> 可重複的模擬器故事資料：Debug build 以 `--smoke-story --open-first-event-detail` 啟動，再開啟 `havencircle://alerts`，會建立長輩家固定圈、載入兩筆 NCDR 歷史示範並直接打開事件詳情。

## 00-home.png｜安心總覽——三秒看懂全家狀態

- **畫面**：安心分頁，主要狀態卡完整顯示「警戒圈一切平安」或明確風險文字，下方可見受守護範圍數與「回報我平安」。
- **怎麼做出來**：載入 Demo 資料後回到安心分頁；截圖前關閉功能導覽遮罩。
- **要呈現的狀態**：不用顏色也能由文字讀懂狀態，設定入口與三分頁列完整。
- **圖說**：打開三秒就知道：警戒圈是否平安、是否有事件靠近、位置是否過期。

## 01-onboarding.png｜新手教學——兩種警戒圈與分享界線

- **畫面**：新手教學第 1 步「歡迎頁」（安心圈標題＋即時圈／固定圈價值卡，含「即時圈由本人開啟、可隨時停止、只走家庭 iCloud」文案）
- **怎麼做出來**：設定分頁最底「刪除帳號與資料」（或全新安裝）→ 重新進入新手教學，停在第 1 步截圖
- **要呈現的狀態**：完整的價值主張文案可讀、無鍵盤遮擋
- **圖說（放進網頁）**：第一個畫面就把界線說清楚：即時圈由本人決定是否分享並標示更新時間；固定圈留在裝置本機。

## 02-alerts.png｜提醒中心——「需要注意」有真實官方事件

- **畫面**：提醒中心分頁，頂部精簡地圖卡（EventsMiniMap），「需要注意」分類下有一筆官方確認事件（內政部消防署・重大火災事件通報【歷史示範】），下方可見「其他區域動態」分類
- **怎麼做出來**：先在家人頁把一個警戒圈（如「長輩家」）設在**彰化縣福興鄉**→ 設定分頁「示範與開發」→「載入歷史官方事件示範」→ 回提醒中心。火災事件（彰化）會命中警戒圈進「需要注意」；台9線封路（花蓮）落在「其他區域動態」，正好同框展示分類邏輯
- **要呈現的狀態**:「需要注意」非空、分類標題清楚、事件卡顯示來源與相對時間
- **圖說**：NCDR 真實示警自動分類——落在家人警戒圈的才「需要注意」，其餘不打擾。

## 03-map.png｜安全地圖——警報塗層＋圖例＋真實避難資源

- **畫面**：安全地圖分頁（全螢幕地圖），畫面同時有：區域警報行政區塗層（紅／橙／黃）、角落展開的圖例面板、避難所或醫院圖層標記、底部「附近更新」卡片列
- **怎麼做出來**：圖層選單開啟「避難所」（或「醫院」）；區域警報塗層吃即時 NCDR 資料，夏季通常有高溫／雷雨示警可入鏡。若當下全台無區域警報，把鏡頭移到有事件點的區域，以事件標記＋圖例＋避難所層構圖
- **要呈現的狀態**：圖例面板展開（嚴重度色階可讀）、至少一層塗色或事件可見、避難所標記可見
- **圖說**：整區的警報用行政區塗層、不用誤導的大頭針；避難所與急救醫院是全國近 6,000 筆政府開放資料。

## 04-event-detail.png｜事件詳情——「為何收到」理由透明

- **畫面**：事件詳情頁（半版摘要上滑至全內容），鏡頭重點：「為何收到」理由列（例：「事件位於長輩家的『住家』警戒圈約 X 公尺內，官方已確認」）＋來源標示（內政部消防署）＋附近緊急資源列與「導航」按鈕
- **怎麼做出來**：延續 02 的狀態，點進「需要注意」裡的火災事件詳情
- **要呈現的狀態**：理由文字完整可讀、來源與可信度標示入鏡、最近避難所（真實資料）與導航按鈕入鏡
- **圖說**：每一則提醒都說得出「為何收到」——來源、可信度、跟哪個警戒圈有關，一行講清楚。

## 05-family.png｜家人——安否回報與已讀回條

- **畫面**：家人分頁的安否回報區：頂部「我平安／需要協助」一鍵回報按鈕，下方家人回報清單，至少一筆回報帶「已讀：⋯」回條
- **怎麼做出來**：需已完成 CKShare 家庭圈邀請的實機（流程見 `CLOUDKIT_SETUP.md`），由另一台裝置發一筆「我平安」，本機查看清單讓已讀回條出現後截圖。若跨帳號環境不可用，退而求其次：截「我平安／需要協助」按鈕＋警戒圈清單的單機畫面，圖說改為「一鍵回報平安，家人即時看到」（不提已讀）
- **要呈現的狀態**：回報按鈕清楚、回報清單有內容、已讀回條可見（理想狀態）
- **圖說**：長輩一鍵回報「我平安」，全家透過 iCloud 即時看到，已讀回條讓關心有了回音。

## 拍攝順序建議（最省事的一條路）

1. 全新狀態跑新手教學 → 拍 **01**；完成後回安心頁拍 **00**
2. 家人頁設「長輩家」警戒圈於彰化縣福興鄉 → 設定頁載入歷史官方事件示範 → 拍 **02** → 點進火災事件 → 拍 **04**
3. 切安全地圖，開避難所圖層＋確認圖例展開 → 拍 **03**
4. 雙機 CKShare 環境發「我平安」→ 拍 **05**
5. 收工：設定頁「重設 Demo 資料」

## 誠實原則備忘

- 示範事件標題自帶【歷史示範】字樣——**不要裁掉或修圖遮蓋**，這正是產品倫理的賣點，網頁圖說會主動說明
- 05 若用單機拍法，網頁圖說同步改用不含「已讀」的版本，不宣稱畫面裡沒有的東西
